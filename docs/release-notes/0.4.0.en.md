### New

- **For your agents (MCP).** OpenBean now ships a read-only MCP server, so your own agent — Claude Code, Claude Desktop, Cursor and others — can list your recordings by date, read summaries and transcripts, and search what was said. Settings → Library → *For agents (MCP)* has the path, a *Copy configuration* button and a ready-made command for Claude Code. It runs only when your agent starts it, never touches Bluetooth and never goes online. What it reads is handed to the agent you connect and the model behind it. Voice-typing history is not exposed.
- **The word list now fixes library transcripts too**, not just voice typing and summaries. Existing transcripts are updated when the word list changes, and the recogniser's original wording is kept, so removing an entry restores it. In long transcripts, same-sound fixes only apply to terms of three characters or more; aliases you declare always apply.

### Improved

- When the recorder is not connected, OpenBean says why (Bluetooth off, no permission, not found, connection lost) instead of showing a greyed-out Sync button.
- Recordings without a title are named the same way everywhere: "2:35 AM", "Yesterday 9:56 PM".
- Sidebar counts now show only what needs attention (still on the recorder, not transcribed).
- An empty library and an empty Overview explain what to do next.
- The Recorder page shows sync progress and has a single Start/Stop recording button.
- Download time for a recording reads "about 2 minutes over Bluetooth".
